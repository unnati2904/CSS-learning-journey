# CSS Mini Projects 🚀

A collection of mini projects and practice demos built while learning CSS. This repository showcases concepts such as Flexbox, Animations, Keyframes, Positioning, and Responsive Design techniques.

## 📂 Projects

### 1. Newton Cradle Animation

A CSS-based animation that simulates the motion of a Newton's Cradle using keyframes and transform properties.

**Concepts Used:**

* CSS Animations
* Keyframes
* Transform Origin
* Pseudo-elements
* Flexbox

### 2. Flexbox Centering Demo

A simple project demonstrating how to center content both horizontally and vertically using Flexbox.

**Concepts Used:**

* Flexbox
* Alignment Properties
* Layout Fundamentals

### 3. Image Carousel

An automatic image slider built using CSS keyframe animations and background image transitions.

**Concepts Used:**

* CSS Animations
* Keyframes
* Background Images
* Responsive Sizing

## 🛠 Skills Practiced

* Flexbox
* CSS Animations
* Keyframes
* Transforms
* Positioning
* Pseudo-elements
* Responsive Design Basics

## 🎯 Goal

To strengthen CSS fundamentals through hands-on projects and build a solid foundation for creating interactive and visually appealing web interfaces.

More projects will be added as the learning journey continues.
