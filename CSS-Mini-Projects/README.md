# CSS Mini Projects 🚀

A collection of mini projects and practice demos built while learning CSS. This repository showcases concepts such as Flexbox, Animations, Keyframes, Positioning, Responsive Design, and Interactive UI Effects.

## 📂 Projects

### 1. Newton Cradle Animation

A CSS-based animation that simulates the motion of a Newton's Cradle using keyframes and transform properties.

**Concepts Used:**

* CSS Animations
* Keyframes
* Transform Origin
* Pseudo-elements
* Flexbox

---

### 2. Flexbox Centering Demo

A simple project demonstrating how to center content both horizontally and vertically using Flexbox.

**Concepts Used:**

* Flexbox
* Alignment Properties
* Layout Fundamentals

---

### 3. Image Carousel

An automatic image slider built using CSS keyframe animations and background image transitions.

**Concepts Used:**

* CSS Animations
* Keyframes
* Background Images
* Responsive Sizing

---

### 4. Glowing Circular Loader

A modern glowing loader animation created using CSS keyframes, pseudo-elements, and rotation effects. The loader features a neon glow that rotates continuously, creating a smooth loading animation.

**Concepts Used:**

* CSS Animations
* Keyframes
* Pseudo-elements (::before, ::after)
* Box Shadow Effects
* Transform & Rotation
* Positioning
* Aspect Ratio

---

### 5. Rain Effect Animation

A realistic rain animation created using CSS background image transitions and keyframe animations. The effect overlays animated raindrops on a background scene to simulate rainfall.

**Concepts Used:**

* CSS Animations
* Keyframes
* Background Images
* Background Positioning
* Infinite Animations
* Full-Screen Layout Design

---

### 6. Shake Button Animation

An interactive button animation that creates a shaking effect when hovered over. This project demonstrates how CSS keyframes can be used to add engaging micro-interactions to user interfaces.

**Concepts Used:**

* CSS Animations
* Keyframes
* Hover Effects
* Transform & Rotation
* Interactive UI Design
* Styling Buttons

---
